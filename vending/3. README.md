# Vending Machine Controller Using Verilog

## Description

This project implements a simple **vending machine controller** using Verilog HDL.

The price of the product is **10 units**.

The machine accepts:

* 5-unit coin
* 10-unit coin

The machine dispenses the product when the inserted amount reaches or exceeds 10 units.

If the user inserts 15 units, the machine dispenses the product and returns **5 units as change**.


## Inputs

| Signal   | Description        |
| -------- | ------------------ |
| `clk`    | Clock signal       |
| `rst`    | Reset signal       |
| `coin5`  | 5-unit coin input  |
| `coin10` | 10-unit coin input |

## Outputs

| Signal     | Description                                   |
| ---------- | --------------------------------------------- |
| `dispense` | Becomes 1 when the product is dispensed       |
| `change5`  | Becomes 1 when 5 units of change are returned |

## Product Price

```text
Product price = 10 units
```

## State Description

The controller uses three states:

| State | Value | Meaning           |
| ----- | ----: | ----------------- |
| `S0`  |  `00` | 0 units inserted  |
| `S5`  |  `01` | 5 units inserted  |
| `S10` |  `10` | 10 units inserted |

## State Transitions

### From S0

```text
5-unit coin  → S5
10-unit coin → Dispense product
```

### From S5

```text
5-unit coin  → Dispense product
10-unit coin → Dispense product + 5-unit change
```

## Working

### Case 1: Insert 5 + 5

```text
5 units → S5
5 units → Product dispensed
```

Output:

```text
dispense = 1
change5  = 0
```

### Case 2: Insert 10

```text
10 units → Product dispensed
```

Output:

```text
dispense = 1
change5  = 0
```

### Case 3: Insert 5 + 10

```text
5 units  → S5
10 units → Product dispensed + 5 units change
```

Output:

```text
dispense = 1
change5  = 1
```

## Result

The vending machine controller successfully accepts 5-unit and 10-unit coins and dispenses the product when the inserted amount reaches the 10-unit price.

It also correctly provides 5 units of change when 15 units are inserted.

## Conclusion

This project demonstrates the use of a **Finite State Machine (FSM)** to design a basic vending machine controller in Verilog HDL.
